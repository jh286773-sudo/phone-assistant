# Ava — Persian Android Assistant

دستیار صوتی فارسی آوا برای اندروید.

## قابلیت‌ها
- تشخیص گفتار فارسی با موتور گفتار نصب‌شده روی گوشی.
- سرویس شنود پس‌زمینه با اعلان foreground و کلیدواژه «آوا» یا «سلام آوا»؛ دکمه شنود برای شروع و توقف سرویس است.
- جستجوی وب و بازکردن نشانی HTTPS.
- تماس با مخاطب یا شماره پس از تأیید؛ شماره‌گیر باز می‌شود و تماس نهایی با لمس کاربر برقرار می‌شود.
- آماده‌سازی پیامک پس از تأیید؛ ارسال نهایی در برنامه پیامک با اقدام کاربر است.
- ترجمه دوطرفه فارسی و زبان دوم از طریق MyMemory.
- دریافت قیمت بیت‌کوین، اتریوم و تتر از CoinGecko.
- قفل صفحه پس از فعال‌سازی دستی Device Administrator.
- تشخیص تماس ورودی و درخواست پاسخ با تأیید کاربر؛ پذیرش تماس به نسخه اندروید و مجوزها وابسته است.

## شنود پس‌زمینه
ابتدا برنامه را باز و مجوز میکروفون را اعطا کنید؛ سپس دکمه «شنود دائمی» را بزنید. اعلان دائمی آوا نمایش داده می‌شود. در صورت تشخیص کلیدواژه، آوا فرمان بعدی را دریافت می‌کند. محدودیت‌های Android 10+ ممکن است بازشدن خودکار صفحه از پس‌زمینه را مسدود کند؛ در این حالت اعلان آوا را لمس کنید. تشخیص گفتار ممکن است به اینترنت و سرویس تشخیص گفتار دستگاه وابسته باشد و تضمین wake word کاملاً آفلاین یا ۱۰۰٪ پیوسته نیست.

## مجوز مدیر دستگاه
برای قفل‌کردن گوشی، آوا صفحه فعال‌سازی Device Administrator را باز می‌کند؛ کاربر باید مجوز را صریحاً فعال کند.

## حریم خصوصی
متن ترجمه برای MyMemory و درخواست قیمت برای CoinGecko ارسال می‌شود. تماس و پیامک بدون تأیید کاربر انجام نمی‌شوند.

## آزمون
GitHub Actions آزمون‌های واحد، کامپایل پایتون و اعتبارسنجی XML را اجرا می‌کند. این آزمون‌ها جایگزین build و تست روی گوشی واقعی نیستند. APK در این گردش‌کار ساخته نمی‌شود.
